rewire-cryptol-2.7: A Haskell-to-Verilog/VHDL compiler, Cryptol foreign functions

The Cryptol-to-Hyle translator behind rwc's Cryptol foreign-function interface (ReWire.Cryptol.cryptol in rewire-user): loads and typechecks a Cryptol module with the Cryptol implementation itself, checks and instantiates a function at a requested monomorphic type, and emits it as ReWire.Hyle definitions. Provides the rwcry executable, which rwc invokes; rwc does not link this package.
